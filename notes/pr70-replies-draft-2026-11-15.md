## Reply to Codex thread 3: "Preserve unexpected native backend failures"

> Fixed in the commit "Add native ALDEx2 differential abundance". Only the
> package's refusal of the data (`CompositionalDA.CompositionError`) becomes an
> `ArgumentError`, which the route reports as 400 `invalid_input`. Any other
> `ErrorException` from the package becomes `NativeBackendFailure`, which is not
> an `ErrorException`, so it never reaches the route's mapping to 422
> `no_taxon_fitted`. It escapes as a server fault. A result that leaves out a
> taxon is also a `NativeBackendFailure`. A non-finite statistic is still
> refused as 422, because that is a property of the data. Tests cover the
> mapping directly (`test/unit/test_differential_native.jl`, "Native aldex2
