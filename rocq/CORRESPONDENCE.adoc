= Rocq recheck leg: statement correspondence
:toc: macro

This file records the Rocq leg that standards `3-practice/PROOF-POLICY.adoc` §2
requires for the Agda counts theorems. It covers §2.2: the proposition, the
assumptions, the type and universe discipline, the revisions, the tool versions,
the invocation, and the result.

Route: *`re-proved`* for every theorem. No Agda→Dedukti→Rocq route is
available in this environment, so each statement was restated in Rocq by hand
and proved by hand. Only the Rocq standard library is used (`Init`, `Arith`,
`List`). No arithmetic decision procedure (`lia`, `omega`, `nia`) appears in
any proof. The proofs use induction, inversion, rewriting with closed
standard-library equations, and two small uses of `auto`.

== Conventions that apply to every row

Each row names only its departures from these conventions.

C1 Names:: Agda `⇒` becomes `_to_`, `-` becomes `_`, and `′` becomes `'`. For
example, `fibre⇒interval` is `fibre_to_interval`. Constructor names keep
their spelling (`z≤n` is `z_le_n`, `is-entailed` is `is_entailed`,
`no-candidate` is `no_candidate`).

C2 Equality:: Agda `_≡_` (in `Set`, under `--without-K`) becomes Rocq `eq`
(in `Prop`). Every equation in these statements is between elements of
`nat`, `Verdict`, `list nat`, `list Row` or `list Checker.Row`. These types have
decidable equality, so identity proofs are unique on both sides and nothing is
lost. Neither side assumes K or UIP.

C3 Order:: Agda `_≤_` (Prelude, in `Set`, constructors `z≤n`, `s≤s`) becomes
`Le` (in `Prop`, written `≤`). `Le` has the same two constructors with the same
implicit arguments. An Agda `m ≤ n` has at most one proof, so moving to `Prop`
loses nothing. `Prelude.Le_iff` proves `Le m n <-> m <= n` against the standard
order.

C4 Negation:: Agda `¬ A = A → ⊥`, where `⊥` is an empty datatype in `Set`,
becomes Rocq `~ A = A -> False`. Both are logically equivalent.

C5 Products:: Agda `A × B` (a non-dependent `Σ` in `Set`) becomes `A /\ B` in
every theorem statement. Every component is a proposition, so the two are
inhabited under the same conditions. A Rocq proof of `/\` cannot be eliminated
into `Type`, but no statement here needs that.

C6 Fibres:: Agda `Candidate observe r E = Σ W (λ w → (observe w ≡ r) × E w)`
becomes `{ w : W | observe w = r /\ E w }` (`sig`, in `Type`, still a
computationally relevant pair), with `fst` becoming `proj1_sig`. The
conclusions `Σ (ReadFibre y n) (λ c → latent (fst c) ≡ x)` become
`{ c : ReadFibre y n | latent (proj1_sig c) = x }`. These are informative on
both sides, and the Rocq proofs end in `Defined`, so the witness computes, as
it does in Agda.

C7 Sorts:: The Agda families in `Set` become propositions in Rocq: `Holds`,
`Sound`, `VerdictView`, `InInterval`, `InBounds`, `Bounded`, `Present`,
`Absent`, `PresenceAgrees` and `LatentsAgree`. The data-carrying types stay in
`Set`/`Type`: `World`, `Direction`, `Candidate`, `ReadFibre`, `Case`, `Int`,
`Verdict`, `Config` and `Row`.

C8 Universes:: The Agda `Core` is level-polymorphic (`W : Set w`, `O : Set o`,
`E : W → Set e`, `P : W → Set p`). The Rocq `Core` takes `W O : Type` but
requires `E P : W -> Prop`. *The ported vocabulary is therefore less general
than Agda's*: it cannot take proof-relevant evidence or claims. This affects
no theorem here, because every instance (`Bounded n`, `Present`, `Absent`) is
propositional. `upto6` likewise takes `P : nat -> Prop` instead of
`P : Nat → Set p`.

C9 Implicit arguments:: Every theorem has the same implicit and explicit
binders as in Agda (checked with `About` on all 22). One difference is not part of any
theorem's type: the parameters `y n` of the `Sound` and `VerdictView`
constructors are implicit in Agda and explicit in Rocq.

C10 Builtins:: Agda's `_+_` is `Nat.add`, `_-_` (truncated) is `Nat.sub`,
`_<_` (Boolean) is `Nat.ltb`, and `_==_` is `Nat.eqb`. The checker's own `not`,
`_∧_` and `_∨_` are `negb`, `andb` and `orb`. Its `length` and `map` are
`List.length` and `List.map`, which have the same clauses (by reading).
`Prelude.builtin_nat_clauses` and
`Checker.bool_clauses` prove that each Rocq function satisfies the defining
clauses of its Agda counterpart. Those clauses are structurally recursive,
so they determine the function, and both sides compute the same values.

C11 Integers:: `Agda.Builtin.Int` (`pos n`, `negsuc n`) is ported as an
inductive of its own with the same two constructors, not as `Z`. `_⊖_`,
`_+ᵢ_`, `absᵢ`, `signᵢ` and `_==ᵢ_` become `minus_int`, `add_int`, `abs_int`,
`sign_int` and `eqb_int`, with the same clauses.
