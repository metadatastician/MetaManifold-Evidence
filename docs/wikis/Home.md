# MetaManifold wiki

This wiki covers [MetaManifold](https://github.com/JoshuaJewell/MetaManifold-WebUI), an amplicon-sequencing pipeline and web app, and **MetaManifold-Evidence**, the separate package in this repository that gives proof-backed presence/absence verdicts on its read counts.

It is a [BerryWiki](https://github.com/metadatastician/berrywiki) notebook: plain Markdown files in `docs/wikis/`, kept in git and reviewed by pull request like the code. The tree on the left is generated by `berrywiki sidebar docs/wikis --write`; do not edit `_Sidebar.md` by hand.

The Evidence package does not import or modify MetaManifold. It reads only what the app already exposes (see its [README](https://github.com/metadatastician/MetaManifold-Evidence/blob/495d9a5d3e61b063dfb404608c1c076ca4cd1463/README.md)).

## How claims are labelled here

Every claim on these pages carries one of these words, and they are not interchangeable:

- **proved**: machine-checked in Agda for all natural numbers, with no postulates;
- **certified on the grid**: the Julia code's output on a finite grid is proved equal to the proved model;
- **tested**: covered by tests, not proved;
- **validated**: agrees with a reference implementation (usually R) within a stated tolerance;
- **proposed**: in an open pull request, not on `main`;
- **not yet built** / **not yet done**: planned, with no code yet.

Facts about MetaManifold-WebUI are measured against `main` at `257bcde` (2026-10-02). Facts about MetaManifold-Evidence are measured against `main` at `495d9a5`. When either moves, a page that cites a line may go stale; the citation tells you what it was checked against.
