# Users

For biologists and analysts who want to go from paired-end FASTQs to results, and to understand what each result can and cannot tell them.

MetaManifold's own [README](https://github.com/JoshuaJewell/MetaManifold-WebUI/blob/257bcdec2db0d4231ed9d5b160b5caa623485681/README.md) is the reference for installation, every configuration key, the output tree and the REST API. These pages give the path through it and point at the right section, so they do not drift from it.
